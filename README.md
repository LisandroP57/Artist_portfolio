# Portfolio de artista (exhibición)
React + Vite + React Router. Todo el contenido está en `src/data.js`.

    npm install
    npm run dev        # desarrollo
    npm run build      # genera /dist

Netlify: Build command `npm run build`, Publish directory `dist` (ya está en netlify.toml, incluye el redirect para las rutas).
Imágenes reales: copiarlas a `public/img/` y cambiar `img` en `data.js`.
